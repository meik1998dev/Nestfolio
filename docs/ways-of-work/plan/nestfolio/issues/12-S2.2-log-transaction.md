# User Story: Log a transaction

**ID:** S2.2 · **Type:** User Story · **Feature:** F2 · **Epic:** E1
**Labels:** `user-story` `priority-critical` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN2.2

## Statement
As **the investor**, I want to **log a transaction** (salary, buy, sell,
transfer) so that **my balances stay accurate**.

## Acceptance Criteria
- [ ] Add transaction: type, from/to account, amount, date.
- [ ] Source and destination balances update correctly.
- [ ] See transactions in a timeline ordered by date.

## Definition of Done
- [ ] Reconcile test (T2.1) passing.
