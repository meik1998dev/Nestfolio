# Technical Enabler: Transaction-leg classifier + reconciliation guard

**ID:** EN6.1 · **Type:** Enabler · **Feature:** F6 · **Epic:** E1
**Labels:** `enabler` `priority-high` `backend`
**Estimate:** 5 pts
**Blocked by:** EN4.1 (transfers), EN4.4 (resolution)

## Description
Turn raw Moralis transfers into classified economic events by grouping per
`transaction_hash` and reading the wallet's IN/OUT legs. Validated rules:

```
2-leg: stock IN  + stablecoin OUT  → BUY      (exact cost = USDT out)
2-leg: stablecoin IN + stock OUT   → SELL     (exact proceeds = USDT in)
1-leg: stock IN only               → DELIVERY (paid off-chain; price via Option A)
1-leg: stock OUT only              → SEND/withdraw
1-leg: stablecoin IN, no stock     → cash deposit (not a trade)
```
Stablecoins = `USDT, USDC, BUSD, FDUSD`.

## Implementation Tasks
- [ ] Group transfers by tx hash; split into IN/OUT legs.
- [ ] Classify each tx by the rules above; emit `{type, ticker, shares, usd?, ts}`.
- [ ] Reconciliation guard: `deposits − buys + sells == current USDT` (else error).
- [ ] Surface unclassifiable txs for review; never drop silently.

## Acceptance Criteria
- [ ] Every trade tx classified correctly on the test wallet.
- [ ] Cash reconciliation passes to the cent (verified: 299.99 − 395.86 + 395.86 = 299.99).

## Definition of Done
- [ ] Classifier + reconciliation unit-tested on real-wallet fixtures.
