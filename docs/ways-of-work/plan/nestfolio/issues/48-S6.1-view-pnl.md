# User Story: See my PnL

**ID:** S6.1 · **Type:** User Story · **Feature:** F6 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN6.3

## Statement
As **the investor**, I want to **see realized, unrealized, and total PnL per holding
and overall** so that **I know how much I've actually made and how much is on paper.**

## Acceptance Criteria
- [ ] Each holding shows: shares, avg cost, live price, unrealized PnL, realized PnL.
- [ ] Portfolio + grand totals show realized / unrealized / total PnL.
- [ ] Prices update on refresh (live equity price, not token DEX price).
- [ ] If cost basis is approximate (Option A historical) it's labeled; exactness improves if Binance import is added later.

## Definition of Done
- [ ] Verified against the validated worked example (T6.1).
