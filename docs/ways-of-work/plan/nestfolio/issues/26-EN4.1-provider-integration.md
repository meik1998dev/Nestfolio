# Technical Enabler: Portfolio API provider integration

**ID:** EN4.1 · **Type:** Enabler · **Feature:** F4 · **Epic:** E1
**Labels:** `enabler` `priority-high` `integration`
**Estimate:** 5 pts
**Blocked by:** EN1.1

## Description
Integrate **Moralis** (free tier) behind a `WalletProvider` interface so it can be
swapped for direct RPC later. **Decision (validated 2026-06-07):** provider =
**Moralis**, not Etherscan/BscScan — the Etherscan V2 unified API dropped BNB chain
from its free tier, so it is NOT free for BSC. Moralis free tier (40k CU/day) covers
BSC and a single-user app's volume at $0. Resolves Open Q #2.

> See `docs/ways-of-work/plan/nestfolio/pnl-and-pricing-method.md` for the validated
> end-to-end approach (tested on a real wallet).

## Implementation Tasks
- [ ] Define `WalletProvider` interface (getBalances(address), getTransfers(address)).
- [ ] Moralis adapter + API key config. Endpoints:
  - balances: `GET /wallets/{address}/tokens?chain=bsc&exclude_spam=true` (use `balance_formatted`)
  - history: `GET /{address}/erc20/transfers?chain=bsc` (paginate via `cursor`)
  - native: RPC `eth_getBalance` or `GET /{address}/balance`
- [ ] Map provider response to internal holding shape.
- [ ] Handle rate limits + retries; send a browser `User-Agent` (Cloudflare blocks default lib UA).

## Validated gotchas (do NOT use these)
- Moralis `usd_price` is a thin-liquidity **DEX price** — unreliable for tokenized
  stocks (e.g. METAon $1518 vs real $593). **Pricing is handled by the PriceProvider
  (EN4.3), not here.**
- `/wallets/.../net-worth` ignores the bsc chain filter (returns eth=$0) → sum tokens.
- `/swaps` returns 0 for this wallet (Ondo/CoW settlements not classified) → use raw transfers.
- `/profitability` returns "Chain is not supported" for BSC → compute PnL ourselves (F6).

## Acceptance Criteria
- [ ] Given a BNB address, returns BNB + BEP20 balances and full transfer history.
- [ ] Balances returned without relying on Moralis stock prices (qty only for stocks).

## Definition of Done
- [ ] Adapter unit-tested against mocked responses.
