# User Story: Net Worth Dashboard (landing)

**ID:** S5.1 · **Type:** User Story · **Feature:** F5 · **Epic:** E1
**Labels:** `user-story` `priority-high` `frontend`
**Estimate:** 5 pts
**Blocked by:** EN5.2

## Statement
As **the investor**, I want **a Net Worth Dashboard as my landing screen** so
that **I instantly see how much I'm worth and where my money is**.

## Acceptance Criteria
- [ ] Shows net worth + month-over-month change.
- [ ] Asset vs liability bars.
- [ ] "Where is my money" breakdown (links to pie S5.4).
- [ ] Loads in < 2s.

## Definition of Done
- [ ] Dashboard E2E (T5.1) passing.
