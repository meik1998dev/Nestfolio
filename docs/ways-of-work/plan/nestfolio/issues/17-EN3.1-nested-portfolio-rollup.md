# Technical Enabler: Nested portfolio + recursive rollup

**ID:** EN3.1 · **Type:** Enabler · **Feature:** F3 · **Epic:** E1
**Labels:** `enabler` `priority-high` `backend`
**Estimate:** 8 pts
**Blocked by:** EN2.3

## Description
Self-referential portfolio tree (`parent_id`) with **flexible (unlimited)
depth**. A portfolio's value = sum of its holdings + value of its child
portfolios, computed recursively.

## Implementation Tasks
- [ ] `parent_id` self-FK + cycle guard.
- [ ] Recursive value rollup (holdings + children).
- [ ] Tree fetch API (subtree + totals).

## Acceptance Criteria
- [ ] Arbitrary depth supported; no cycles allowed.
- [ ] Rolled-up totals correct at every node.

## Definition of Done
- [ ] Rollup tests (T3.1) green for depth ≥3.
