# User Story: Future projection

**ID:** S5.5 · **Type:** User Story · **Feature:** F5 · **Epic:** E1
**Labels:** `user-story` `priority-medium` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN5.2

## Statement
As **the investor**, I want **a 5–10 year projection of my wealth** so that **I
can see where I'm headed** at my current savings rate.

## Acceptance Criteria
- [ ] Inputs: current net worth, monthly savings, assumed return.
- [ ] Three scenarios: conservative / expected / optimistic.
- [ ] Compound-growth math; chart + figures.

## Definition of Done
- [ ] Projection math (T5.1) verified.
