# Technical Enabler: Asset source + wallet_ref

**ID:** EN3.2 · **Type:** Enabler · **Feature:** F3 · **Epic:** E1
**Labels:** `enabler` `priority-high` `backend`
**Estimate:** 3 pts
**Blocked by:** EN2.3

## Description
Every holding records provenance: `source` = `ON_CHAIN | MANUAL`, plus a
`wallet_ref` when on-chain. Drives trust and the manual-assignment flow.

## Implementation Tasks
- [ ] `source` enum + `wallet_ref` column on holdings.
- [ ] Surface source in holding APIs and UI badges.
- [ ] Validation: on-chain requires wallet_ref; manual forbids it.

## Acceptance Criteria
- [ ] Holdings display their source (e.g. "PAXG · Binance" vs "Gold · Manual").

## Definition of Done
- [ ] Validation tested.
