# User Story: Log a categorized expense

**ID:** S2.3 · **Type:** User Story · **Feature:** F2 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 2 pts
**Blocked by:** EN2.2

## Statement
As **the investor**, I want to **log expenses with a category** so that **I can
see where my money goes each month**.

## Acceptance Criteria
- [ ] Expense transaction carries a category (rent, food, transport, other…).
- [ ] Monthly breakdown by category renders from logged expenses.
- [ ] Categories are user-manageable.

## Definition of Done
- [ ] Category breakdown verified by test.
