# Technical Enabler: Transaction engine

**ID:** EN2.2 · **Type:** Enabler · **Feature:** F2 · **Epic:** E1
**Labels:** `enabler` `priority-critical` `backend`
**Estimate:** 8 pts
**Blocked by:** EN2.1

## Description
The single engine for all value movement. One transaction shape covers every
operation via `type` + `source_account` → `dest_account`.

## Types
`income` (External→Account) · `buy` (Cash→Asset) · `sell` (Asset→Cash) ·
`transfer` (Account→Account) · `expense` (Account→Expense).

## Implementation Tasks
- [ ] Transaction model + create/list/update/delete API.
- [ ] Apply rules per type to source/dest balances.
- [ ] Validation: required accounts per type, non-negative amounts, date.
- [ ] Idempotent re-derivation of balances from the transaction log.

## Acceptance Criteria
- [ ] Each type debits source and credits dest correctly.
- [ ] Net of all transactions reconciles to current balances.

## Definition of Done
- [ ] Reconcile unit tests (T2.1) green.
