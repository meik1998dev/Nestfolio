# User Story: Create nested portfolios

**ID:** S3.1 · **Type:** User Story · **Feature:** F3 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN3.1

## Statement
As **the investor**, I want to **create portfolios that contain sub-portfolios
to any depth** so that **my structure matches reality** (e.g. Stocks → NVDA/MSFT).

## Acceptance Criteria
- [ ] Create a portfolio under any parent.
- [ ] View the tree with rolled-up values per node.
- [ ] Move/rename/delete portfolios (no cycles).

## Definition of Done
- [ ] Tree renders correct totals at depth ≥3.
