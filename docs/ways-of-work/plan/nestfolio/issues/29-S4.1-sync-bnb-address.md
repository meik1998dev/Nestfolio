# User Story: Sync a BNB address

**ID:** S4.1 · **Type:** User Story · **Feature:** F4 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN4.2

## Statement
As **the investor**, I want to **paste my public BNB address and sync balances**
so that **my crypto assets appear automatically** — no signature, no permission.

## Acceptance Criteria
- [ ] Enter a public address; trigger sync (async with loading state).
- [ ] BNB + BEP20 balances appear with USD values.
- [ ] Synced tokens go to the unassigned bucket for assignment.
- [ ] Failed sync shows last-known balances + an error, never blank.

## Definition of Done
- [ ] Sync flow verified (T4.1).
