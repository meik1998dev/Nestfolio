# User Story: Create accounts

**ID:** S2.1 · **Type:** User Story · **Feature:** F2 · **Epic:** E1
**Labels:** `user-story` `priority-critical` `fullstack`
**Estimate:** 2 pts
**Blocked by:** EN2.1

## Statement
As **the investor**, I want to **create accounts** (cash, gold, wallet, stock)
so that **I have places to hold and move value**.

## Acceptance Criteria
- [ ] Add an account with name + type + currency.
- [ ] See a list of my accounts with current balances.
- [ ] Edit or archive an account.

## Definition of Done
- [ ] Code review approved; covered by F2 tests.
