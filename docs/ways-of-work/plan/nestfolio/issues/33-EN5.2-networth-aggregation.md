# Technical Enabler: Net-worth aggregation service

**ID:** EN5.2 · **Type:** Enabler · **Feature:** F5 · **Epic:** E1
**Labels:** `enabler` `priority-high` `backend`
**Estimate:** 5 pts
**Blocked by:** EN3.1, EN4.3

## Description
Single service computing `Net Worth = Σ assets − Σ liabilities`, plus breakdowns
by portfolio and asset class. Used by the dashboard, snapshots, and reviews.

## Implementation Tasks
- [ ] Aggregate holding values (priced) across the portfolio tree.
- [ ] Subtract liabilities.
- [ ] Produce breakdown (by portfolio + by asset class) for charts.

## Acceptance Criteria
- [ ] Net worth matches sum of priced holdings minus liabilities.
- [ ] Breakdown percentages sum to 100%.

## Definition of Done
- [ ] Aggregation unit tests (T5.1) green.
