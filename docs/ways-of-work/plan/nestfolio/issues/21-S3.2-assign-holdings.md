# User Story: Assign holdings to portfolios

**ID:** S3.2 · **Type:** User Story · **Feature:** F3 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 2 pts
**Blocked by:** EN3.2, EN4.2

## Statement
As **the investor**, I want to **assign each holding (synced or manual) to a
portfolio** so that **on-chain assets land in the right category** (e.g. PAXG → Gold).

## Acceptance Criteria
- [ ] Synced tokens appear in an "unassigned" bucket.
- [ ] I assign each holding to a portfolio manually.
- [ ] Reassigning updates rollups immediately.

## Definition of Done
- [ ] Manual-assignment flow works for on-chain and manual holdings.
