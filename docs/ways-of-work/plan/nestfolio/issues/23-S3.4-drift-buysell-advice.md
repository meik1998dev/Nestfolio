# User Story: See drift + buy/sell advice

**ID:** S3.4 · **Type:** User Story · **Feature:** F3 · **Epic:** E1
**Labels:** `user-story` `priority-high` `frontend`
**Estimate:** 3 pts
**Blocked by:** EN3.3

## Statement
As **the investor**, I want to **see drift and exact buy/sell amounts at each
level** so that **I know precisely what to trade to rebalance**.

## Acceptance Criteria
- [ ] Table per level: target %, actual %, drift, suggested trade.
- [ ] Suggestions cover top-level AND within-portfolio (e.g. NVDA/MSFT/AAPL).
- [ ] Amounts bring each level to target within rounding.

## Definition of Done
- [ ] Matches engine output (T3.1).
