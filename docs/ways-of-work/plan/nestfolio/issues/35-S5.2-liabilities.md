# User Story: Track liabilities

**ID:** S5.2 · **Type:** User Story · **Feature:** F5 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN5.2

## Statement
As **the investor**, I want to **track debts (loans, credit cards)** so that
**my net worth reflects what I truly own**.

## Acceptance Criteria
- [ ] Add/edit/delete liabilities (name, type, balance).
- [ ] Liabilities reduce net worth on the dashboard.
- [ ] Shown alongside assets in the balance view.

## Definition of Done
- [ ] Net worth = assets − liabilities verified.
