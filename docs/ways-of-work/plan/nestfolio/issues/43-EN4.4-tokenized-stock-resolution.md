# Technical Enabler: Tokenized-stock resolution (token → ticker)

**ID:** EN4.4 · **Type:** Enabler · **Feature:** F4 · **Epic:** E1
**Labels:** `enabler` `priority-high` `integration`
**Estimate:** 2 pts
**Blocked by:** EN4.1

## Description
Resolve on-chain tokenized-stock tokens to their underlying equity ticker so the
PriceProvider (EN4.3) can value them. **Decision (validated 2026-06-07):** the
user's tokenized stocks are **Ondo Global Markets** BEP-20 tokens on BNB chain,
symbol suffix **`on`** and name `"… (Ondo Tokenized)"` (e.g. `NVDAon`→NVIDIA,
`METAon`→Meta, `GOOGLon`→Alphabet). Resolves Open Q #4. (xStocks / Kraken–Backed
`…x` tokens may also appear later — handle via the same map.)

## Implementation Tasks
- [ ] Detect tokenized stocks (symbol ends `on` / name contains "Ondo Tokenized").
- [ ] Map symbol → equity ticker: strip trailing `on`; keep an override map for edge cases.
- [ ] Expose `{ ticker, displayName, issuer }` for pricing + UI.
- [ ] Allow manual override per token (mis-mapped or new issuer).

## Acceptance Criteria
- [ ] Each held tokenized stock resolves to a valid equity ticker (14/14 on test wallet).
- [ ] Unknown/unmapped tokens flagged for manual mapping, never silently mispriced.

## Definition of Done
- [ ] Mapping unit-tested against the real wallet's 14 tokens + override path.
