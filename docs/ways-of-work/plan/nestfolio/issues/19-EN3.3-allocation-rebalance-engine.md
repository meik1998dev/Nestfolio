# Technical Enabler: Allocation + rebalance engine (all levels)

**ID:** EN3.3 · **Type:** Enabler · **Feature:** F3 · **Epic:** E1
**Labels:** `enabler` `priority-high` `backend`
**Estimate:** 8 pts
**Blocked by:** EN3.1

## Description
Store target % per portfolio at any level. Compute drift (target vs actual) and
the exact buy/sell amounts to return each level to target — recursively, both
across top-level portfolios and within each one.

## Implementation Tasks
- [ ] Target % field per portfolio + validation (siblings sum to 100%).
- [ ] Recursive drift calc (actual % vs target % at each node).
- [ ] Trade suggestion: per node, amount to buy/sell to hit target.
- [ ] Decide & implement Open Q #5 (relative-to-parent vs absolute).

## Acceptance Criteria
- [ ] Drift shown at every level.
- [ ] Suggested trades bring each level to target within rounding.

## Definition of Done
- [ ] Rebalance math tests (T3.1) green.
