# Technical Enabler: PnL engine (realized / unrealized / total)

**ID:** EN6.3 · **Type:** Enabler · **Feature:** F6 · **Epic:** E1
**Labels:** `enabler` `priority-high` `backend`
**Estimate:** 3 pts
**Blocked by:** EN6.2 (ledger), EN4.3 (live price)

## Description
Combine the cost-basis ledger with live equity prices to produce PnL per holding
and rolled up per portfolio (reuses F3 recursive rollup).

```
unrealized = shares_now × livePrice(ticker) − cost_remaining
realized   = Σ realized from disposals (from EN6.2)
total      = realized + unrealized
```
Note: **unrealized uses TODAY's live price** (open position); realized/cost use
price-at-transaction-time.

## Implementation Tasks
- [ ] **Two-speed recompute:** realized recomputed only on new `trade_events` (heavy sync); unrealized recomputed on each live-price refresh (light) — pure DB math, no chain/history calls.
- [ ] Read realized + cost from `cost_basis`; multiply remaining shares by `live_prices`.
- [ ] Roll up PnL per portfolio at every nesting level (reuse EN3.1 rollup).
- [ ] Expose totals for the dashboard (S6.1 / F5) straight from DB (instant read).
- [ ] Degrade gracefully if a live price is unavailable (last-known + flag).

> Wired by the orchestrator (EN4.5). See `sync-and-persistence-design.md`.

## Acceptance Criteria
- [ ] Per-holding and portfolio-level realized/unrealized/total PnL returned.
- [ ] Totals tie out: Σ holding PnL == portfolio PnL == grand total.

## Definition of Done
