# User Story: Transaction notes

**ID:** S2.4 · **Type:** User Story · **Feature:** F2 · **Epic:** E1
**Labels:** `user-story` `priority-medium` `frontend`
**Estimate:** 1 pt
**Blocked by:** EN2.2

## Statement
As **the investor**, I want to **add a note to any transaction** so that **I can
record why I bought or sold** (lightweight reasoning, no separate journal).

## Acceptance Criteria
- [ ] Free-text note field on create/edit.
- [ ] Note displays on the transaction in the timeline.

## Definition of Done
- [ ] Note persists and renders.
