# User Story: Monthly wealth review

**ID:** S5.6 · **Type:** User Story · **Feature:** F5 · **Epic:** E1
**Labels:** `user-story` `priority-medium` `fullstack`
**Estimate:** 3 pts
**Blocked by:** EN5.1, EN5.2

## Statement
As **the investor**, I want **an auto monthly review** so that **I understand
what changed my net worth each month**.

## Acceptance Criteria
- [ ] Month-end summary: net-worth change, biggest winner/loser.
- [ ] Salary added vs investment gains split.
- [ ] Generated from snapshots + transactions (no manual work).

## Definition of Done
- [ ] Review renders for a completed month.
