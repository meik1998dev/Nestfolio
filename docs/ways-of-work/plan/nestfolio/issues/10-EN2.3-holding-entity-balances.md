# Technical Enabler: Holding entity + balance derivation

**ID:** EN2.3 · **Type:** Enabler · **Feature:** F2 · **Epic:** E1
**Labels:** `enabler` `priority-critical` `backend`
**Estimate:** 5 pts
**Blocked by:** EN2.2

## Description
A Holding is a position in one asset (amount) tied to an account/portfolio.
Holding amounts derive from buy/sell/transfer transactions (and later from
wallet sync).

## Implementation Tasks
- [ ] Holding model (asset, amount, source, wallet_ref, portfolio_id).
- [ ] Derive/update amounts from transactions.
- [ ] USD valuation hook (price × amount) — price source plugged in F4.

## Acceptance Criteria
- [ ] Buying/selling an asset updates its holding amount.
- [ ] Holding value = amount × current price.

## Definition of Done
- [ ] Unit tests on derivation.
