# Technical Enabler: PriceProvider (stocks + gold/PAXG + crypto)

**ID:** EN4.3 · **Type:** Enabler · **Feature:** F4 · **Epic:** E1
**Labels:** `enabler` `priority-high` `integration`
**Estimate:** 5 pts (was 3 — scope expanded after validation)
**Blocked by:** EN4.1

## Description
A `PriceProvider` that returns **live and historical** USD prices, kept SEPARATE
from the balance source. **Critical rule (validated 2026-06-07): never value a
tokenized stock by its on-chain/DEX price** — those Ondo tokens have thin liquidity
and the DEX price is wrong (overstated the test portfolio ~2.5×: $6,426 vs the
correct $2,284). Value tokenized stocks by the **underlying equity price**.

> Full method + validation: `docs/ways-of-work/plan/nestfolio/pnl-and-pricing-method.md`

## Price routing (by asset type)
```
Tokenized stocks (…on)  → underlying equity price (NOT the DEX price)
Gold grams (manual)     → XAUUSD spot, per-gram
PAXG / crypto / BNB     → Moralis usd_price (deep liquidity = reliable) or feed
```

## Provider choice (validated)
- **Primary: `yahoo-finance2` (npm)** — free, no key, live **and** historical; handles Yahoo cookie/crumb.
- **Fallbacks:** Finnhub (live, free — confirmed working) · Twelve Data (historical, free).
- Map token → ticker via EN4.4 (strip `on`: `NVDAon`→`NVDA`).

## Implementation Tasks
- [ ] `PriceProvider` interface: `livePrice(ticker)`, `histPrice(ticker, date)`, `goldPerGram()`.
- [ ] yahoo-finance2 adapter (live + historical) + Finnhub/Twelve Data fallback.
- [ ] **`live_prices` cache (TTL):** refresh only when stale (1–5 min, market hours; off-hours = last close).
- [ ] **`price_history` cache (immutable):** fetch a `(ticker, date)` once, store, never overwrite; serve from DB thereafter.
- [ ] Store price source + timestamp for traceability.
- [ ] Resolve Open Q #3 (gold feed = Yahoo XAUUSD spot per gram).

> Caching tables defined in EN1.2; orchestration in EN4.5. See `sync-and-persistence-design.md`.

## Acceptance Criteria
- [ ] Tokenized stock → real equity price (live + historical), not DEX price.
- [ ] Manual gold grams and PAXG resolve to USD values.
- [ ] Falls back to keyed provider when primary throttles (graceful).

## Definition of Done
- [ ] PriceProvider unit-tested (incl. fallback path + token→ticker mapping).
