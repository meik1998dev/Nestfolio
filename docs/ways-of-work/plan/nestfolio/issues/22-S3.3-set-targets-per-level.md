# User Story: Set allocation targets per level

**ID:** S3.3 · **Type:** User Story · **Feature:** F3 · **Epic:** E1
**Labels:** `user-story` `priority-high` `fullstack`
**Estimate:** 2 pts
**Blocked by:** EN3.3

## Statement
As **the investor**, I want to **set target % for portfolios at any level** so
that **the app can compare reality to my policy** (e.g. Gold 70 / Crypto 25 / Stocks 5).

## Acceptance Criteria
- [ ] Set/edit target % on any portfolio node.
- [ ] Sibling targets validated to sum to 100%.
- [ ] Targets persist and feed the rebalance view.

## Definition of Done
- [ ] Validation + persistence tested.
