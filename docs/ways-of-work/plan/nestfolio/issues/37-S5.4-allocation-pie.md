# User Story: Asset-allocation pie

**ID:** S5.4 · **Type:** User Story · **Feature:** F5 · **Epic:** E1
**Labels:** `user-story` `priority-medium` `frontend`
**Estimate:** 2 pts
**Blocked by:** EN5.2

## Statement
As **the investor**, I want **a pie chart of my allocation** so that **I can see
where my money sits at a glance** (Gold / Crypto / Stocks / Cash).

## Acceptance Criteria
- [ ] Pie by asset class with % labels.
- [ ] Reflects current priced holdings.
- [ ] Drill into a portfolio's own breakdown.

## Definition of Done
- [ ] Percentages match aggregation service.
